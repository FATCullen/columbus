Source: The data in this archival information package (NODC accession
0098060) is the content of NODC standard CD-ROM product Ocean Current Drifter
Data on CD-ROM, NODC-53 and NODC-54. All data on these discs were extracted 
from other data collections archived at the National Oceanographic Data Center 
at the time the discs were created in 1991.

Actions: ISO disc images of the original disc were created using standard
disc duplication software and copied to data/0-data/disc_image/ directory. The
content of the original disc were copied 'as is' to data/0-data/disc-content/
directory.  Any software that were provided on these discs or used as a supple-
ment to these discs are considered obsolete and are not included in 0-data/disc_contents.

Files:
about/
This directory contains files created by NODC staff that describe the
contents of the disc.

data/0-data/
This directory contains the data files from the original NODC-xx disc.

data/0-data/disc_image/
This directory contains an ISO disc image files that can be used by several
CD-ROM authoring software applications to create an exact duplicate of the 
original disc.

data/0-data/disc_contents/
This directory contains all of the individual directories and files, in
their original order, to provide direct access to the original data on
original disc, excluding any software files.
